# V1.1 – Analyse von V1.0 und Plan (Arbeitsnotiz)

## Vorgefundene Architektur (V1.0)

* Statische ES-Module ohne Build. `js/main.js` verdrahtet Zustand (`core/state.js`, Version 1),
  Wirtschaft (`core/economy.js`, Tickets mit Einmal-Auszahlung), Progression, Audio/Haptik,
  HUD, Halle (`hub/`) und Hash-Router. Spiele: `mount(root, ctx)` → `{destroy, finalize?, pause?}`.
* Reine, in Node testbare Logikmodule je Spiel (`logic.js`/`physics.js`/`engine.js`).
* Gemeinsam: Partikel-Overlay (`ui/fx.js`), Ergebnis-Banner (`ui/banner.js`), Einsatzsteuerung.
  Gewinn-Feedback ist aber in jedem Spiel einzeln und uneinheitlich gelöst.
* Tests: 36 Unit-Tests, 32 E2E-Checks (mit festen Wartezeiten → teils fragil).

## Gefundene Economy-Probleme (Simulation: `sim/v10-baseline.mjs`)

| Spiel | Problem | Erwartete Rückzahlung V1.0 |
|---|---|---|
| Lichtwirbel | Start immer gegenüber dem Jackpot → reines Intervall-Timing; 61 ms pro Feld; 25× | 10× – 25× des Einsatzes (σ 70 → 8 ms) |
| Turmbau | Schritte ≥ 55 ms, Jackpot 15× | 6× – 15× für gute Spieler |
| Neon Hoops | ~60 Würfe, Multiplikatoren stapeln sich, Preis bis 8× | 1,3× schon bei 30 % Treffern, bis 8× |
| Gratis-Nachschub | 500 Credits ohne Wartezeit → endloser „Freeroll“ auf Hochrisiko-Wetten | unbegrenzt |
| Level-Bonus | 100 × Level, XP an Einsatzhöhe gekoppelt → Rabatt-Farming | positiv bei niedrigem Hausvorteil |
| Kosmo 5 | Nova-Linien (bis 2000×) stehen in der Gewinntabelle, sind aber unmöglich (Walze 1/5 ohne Nova) | irreführende Tabelle |

## Plan V1.1

1. Economy-Leitplanken: Zufallsspiele RTP 92–97 %, Skillgames mit Startgebühr + gedeckelter
   Preistabelle und steigender Schwierigkeit innerhalb einer Runde. Ziel-RTP Skill: Zufall ≤ 0,5,
   Durchschnitt 0,6–0,8, gut ~1,0, Elite ≤ ~1,3; Elite-Verdienst ≲ 1.000 Credits/Stunde/Spiel.
2. Max-Einsätze je Spiel, maximaler Einzelgewinn je Runde ≲ 50.000.
3. Nachschub mit Wartezeit, Level-Bonus und XP entkoppelt von der Einsatzhöhe.
4. State v2 mit Migration aus v1.
5. Gemeinsames Gewinnstufen-System (`core/wintier.js` + `ui/celebrate.js`).
6. Spielkontrolle: Pause, Selbstsperre, Hilfe, Session-Erinnerung (`core/control.js`).
7. Tages-Challenges (`core/challenges.js`).
8. Neue Spiele: Plinko, Münzgreifer, Pferderennen; Münzkaskade 2.0; Lichtwirbel neu.
9. Tests deutlich erweitern, E2E ohne feste Wartezeiten.
