FAQ

Antworten zu Spielstart, Speicherung, Multiplayer, Rangliste und Geräten.

Muss ich etwas installieren?

Nein. Das Spiel startet direkt in einem modernen Browser. Für die beste Bedienung sollte JavaScript aktiviert sein.

Benötige ich ein Konto?

Nein. Neon Bot Arena besitzt kein Login-System. Für die Rangliste wird ein frei gewählter Spitzname verwendet. Bitte nutze nicht deinen echten Namen.

Wo wird mein Fortschritt gespeichert?

Münzen, freigeschaltete Inhalte, Einstellungen und lokale Rekorde werden im Browser des verwendeten Geräts gespeichert. Browserdaten zu löschen kann diesen Fortschritt entfernen.

Wie funktioniert Koop?

Eine Person erstellt im Multiplayer-Menü eine Lobby. Die zweite Person tritt mit dem angezeigten vierstelligen Lobbycode bei. Für eine gemeinsame Runde benötigen beide eine Internetverbindung.

Warum kann eine Lobby nicht gefunden werden?

Der Code muss zur aktuell geöffneten Lobby gehören. Nach einem Serverneustart oder nachdem die Lobby geschlossen wurde, ist ein alter Code nicht mehr gültig.

Läuft das Spiel auf Smartphone und Tablet?

Ja. Auf Touch-Geräten erscheinen ein virtueller Bewegungsstick, eine Feuertaste und eine Taste für die Spezialfähigkeit.

Wie lösche ich gespeicherte Daten?

In den Einstellungen gibt es „Alles löschen“. Vor dem Löschen erscheint eine Warnung. Hinweise zur Online-Rangliste stehen zusätzlich in der Datenschutzerklärung und im Spiel.

Ist das Spiel kostenlos?

Ja. Spielmünzen werden durch das Spielen verdient und sind keine Echtgeld-Währung. Aktuell gibt es keine Käufe mit echtem Geld.
